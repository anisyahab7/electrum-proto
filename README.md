Electrum protocol shell — stub server tag.

## Features

- BTC path m/84'/0'/0'
- Local derive + address codec
- C++20, CMake, no third-party fetch

## Prerequisites

- CMake 3.20+
- A C++20 compiler
- Git

## Getting Started

```bash
git clone <repo-url>
cd electrum-proto
cmake -B build
cmake --build build
ctest --test-dir build --output-on-failure
```
